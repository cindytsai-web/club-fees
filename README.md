# 羽球社分帳（club-fees）

參考 Spliit「不用一筆一筆記帳」的做法：每週只填場地費、球數與雜費，網頁自動算出每位出席者要付多少。

線上版：<https://cindytsai-web.github.io/club-fees/>

## 使用方式

用瀏覽器打開線上網址即可；也可以下載 `index.html` 雙擊使用，不需要安裝任何東西、不需要伺服器。

## 計算規則

- 場地費：直接填本週場地總額
- 球費：每顆單價 × 本週用球數
- 雜費：飲料、停車等，可留空
- 分攤：總費用由當週出席者平均分攤
- 新人優惠：勾選「首次」的人這週免費，費用由其他人分攤
- 臨打：與社員一樣平均分攤
- 收費取整：可選不取整、進位到整數、5 元或 10 元

## 功能

- 社員名單管理（新增、改名、刪除）
- 每週出席勾選與首次免費標記
- 歷史紀錄：儲存每週結果、查看明細、複製摘要貼到群組
- 離線可用：資料會先存在瀏覽器，恢復連線後自動同步

## 雲端同步

資料存在 Supabase（Postgres），換手機、換電腦看到的是同一份。

- 打開網頁**不需要密碼**就能看到目前資料（唯讀）
- 要**修改**資料需要社群密碼，右上角狀態標籤會顯示：
  - 綠色「已同步」＝ 已連上雲端
  - 黃色「需解鎖」＝ 請輸入密碼才能儲存
  - 紅色「離線」＝ 網路或資料庫連不上，資料暫存在本機
- 連續輸入錯誤 5 次會鎖定 60 秒
- 若有人同時修改，較慢的那次會自動重新載入最新資料

### 安全設計

- 資料表啟用 Row Level Security：匿名者只能讀取，**不能**新增、修改、刪除
- 寫入一律經過資料庫端的 `club_save()` 函式，密碼以 bcrypt 雜湊比對
- 密碼本身存在 `club_config` 表，前端完全讀不到
- 網頁中的 `sb_publishable_...` 金鑰是設計給瀏覽器公開使用的，不是機密

## Excel 版

`club-fees.xlsx` 是同樣規則的試算表版本，包含「本週分帳」與「歷史紀錄」兩個工作表，公式會自動計算每人應付。
