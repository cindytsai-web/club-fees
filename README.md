# 羽球社分帳（club-fees）

參考 Spliit「不用一筆一筆記帳」的做法：每週只填場地費、球數與雜費，網頁自動算出每位出席者要付多少。

## 使用方式

直接用瀏覽器打開 `index.html`（雙擊即可），不需要安裝任何東西，也不需要伺服器。

## 計算規則

- 場地費：直接填本週場地總額
- 球費：每顆單價 × 本週用球數
- 雜費：飲料、停車等，可留空
- 分攤：總費用由當週出席者平均分攤
- 新人優惠：勾選「首次」的人這週免費，費用由其他人分攤
- 臨打：與社員一樣平均分攤
- 收費取整：可選不取整、進位到整數、5 元或 10 元

## 功能

- 社員名單管理（新增、改名、刪除）
- 每週出席勾選與首次免費標記
- 歷史紀錄：儲存每週結果、查看明細、複製摘要貼到群組
- 資料存在瀏覽器的 localStorage，請固定使用同一個瀏覽器開啟

## Excel 版

`club-fees.xlsx` 是同樣規則的試算表版本，包含「本週分帳」與「歷史紀錄」兩個工作表，公式會自動計算每人應付。
